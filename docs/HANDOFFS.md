# Results, handoffs and next actions

A specialist contribution should contain the assigned work, relevant evidence and important assumptions. Review checks it against the request. Final assembly resolves conflicts and turns the contributions into a readable deliverable.

Useful handoffs include turning a campaign plan into draft posts, a research brief into a presentation outline, an analysis into a budget specification or meeting notes into follow-up drafts. The handoff carries the approved task context, not a claim that an external action has already happened.

Text, documents and available export formats should be distinguished from publication or execution. Social posts need an authorised channel tool; code needs actual execution and tests; media needs a generator; financial and employment outcomes remain with the appropriate human decision makers.
