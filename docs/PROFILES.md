# Reusable profiles and custom teams

Profiles express how you want recurring work delivered: tone, format, reusable instructions, team preference and relevant knowledge/memory choices. Custom teams express who contributes: selected specialists, reviewer and bounded collaboration preferences.

A task template expresses what you need. An agent role expresses a responsibility. A model supplies inference. Keeping these concepts distinct makes a profile reusable across requests without implying a new model is trained for every team.

The workspace supports explicit composition through the available `@` and selection controls. Configuration uses actual available role and model entries. Local qualification remains required. This documentation does not publish private saved profile contents or internal orchestration prompts.
